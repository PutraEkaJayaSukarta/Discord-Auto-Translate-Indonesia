# Contributing

Thanks for helping improve this project.

## Before submitting a change

- Keep the original Key-Intercept attribution intact.
- Do not commit Discord tokens, cookies, API keys, or other secrets.
- Keep translation-specific code isolated where practical.
- Test `translator-server.js` with `node --check translator-server.js`.
- Test the Vencord plugin in a disposable/test Discord environment when possible.

## Pull requests

Please explain:

1. What changed.
2. Why it changed.
3. How you tested it.
4. Whether the change affects outgoing translation, incoming translation, or the toggle.

## Reporting security issues

Do not publish credentials or sensitive account information in a public issue.
